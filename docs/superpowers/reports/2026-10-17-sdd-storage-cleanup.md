# SDD 验证产物磁盘清理记录

## 原因与结果

用户发现主工作树 `.superpowers/sdd/` 超过 50 GiB。独立只读审计确认，四个工作树累计约 84.45 GiB，主要来自每轮重复归档工具链和模块源码、任务独占构建缓存、遗留测试及运行时二进制。这是验证产物管理失控，不是业务数据增长。

按明确路径、文件类型、所有权及删除前文件身份检查，删除历史重复归档、可重建二进制和闲置构建缓存，共 74,063,159,296 字节（约 68.98 GiB）。另将 1,394 份大型历史依赖输入记录无损压缩，逐份核对解压后的 SHA-256，节省 7,278,178,304 字节（约 6.78 GiB）。合计回收约 75.76 GiB。

清理后实测：

| 位置 | 剩余占用 |
| --- | ---: |
| 主工作树 `.superpowers/sdd/` | 7.7 GiB |
| `etcd-worker-role` 工作树 | 465 MiB |
| `fuse-resident-readiness` 工作树 | 402 MiB |
| `etcd-pending-validation` 工作树 | 135 MiB |

磁盘可用空间从 18 GiB 恢复到 97 GiB。数值为本机 `du`、`df` 的当次结果，存在显示取整及其他进程写入影响。

## 保留与清理边界

保留源码、Git 历史、命令和结果日志、小型清单及审查记录；当前尚未完成审计的 worker metadata 任务产物完整保留。保留唯一模块缓存及一份共享构建缓存，不操作业务数据、现有 Docker 容器或无关文档。

历史大型输入记录改为 `.json.gz`，内容哈希不变。已完成任务的重复源码归档和二进制被删除，不能再引用这些已删除文件声称重新执行了历史归档审计；已有验收记录保留。逐文件删除和压缩清单位于本机忽略目录 `.superpowers/sdd/2026-10-17-storage-cleanup/`。

## 防止再次增长

`AGENTS.md` 增加验证产物规范：所有工作树复用主仓库 `.superpowers/sdd/_cache/go-build`，模块缓存仅保留一份；禁止每轮重复打包工具链和整个模块缓存；任务完成后清理可重建产物。

当前 metadata 验证脚本已改用共享缓存，依赖输入记录即时压缩并核对解压内容，源码快照只含仓库输入并按内容复用，不再重复归档第三方依赖或工具链；可用空间低于 10 GiB 时拒绝启动本次验证。配套审计脚本兼容压缩清单和仓库范围快照。已通过 Bash 及内嵌 Python 语法检查；清理期间未重新运行 Go 测试，未将脚本语法检查描述为迁移功能验收。
