# 终态 pending 独立删除切片验证

已实现新任务终态 pending 的独立冷删除；尚未接通自动消费者，也没有完成真实签名
成功删除或实际物理链验收。本片不修改满64节点的 owner-release、执行占用、槽或 Run。

删除要求原 worker/分区/Claim 份额、共同出生证据、原私有签名读取器产生的释放证明，
以及精确存在的 pending。execution 必须缺失或已 settled；缺失 pending 是过期观察拒绝，
不能成为不经比较的成功。真实会话须为60秒，调用前与构造时检查剩余生命周期。

一次原 Claim 对应一个 CAS，保留 W20、Task/intent/初始回执、execution、签名释放与
pending 的原精确比较。execution 缺失/存在分别41/44比较，最高47原生节点。实际请求
先校验，再做封闭键职责的最大 protobuf 投影，请求95232字节、成功4096字节、失败
14592字节均在原限制内。投影只计费，不授予删除权限；回填原52节点形状保持不变。

失败 CAS 必须确认身份、restore 和原 owner 后检才能作为 Conflict 返回；取消、未知
响应或丢 ACK 使会话失效，等待实际调用结束，不退还信用或猜测已经删除。

## 实际验证

- 编译 RED 仅缺三个批准的私有接口，没有运行断言，原始记录保留。
- host 两组15叶例通过，0.813s；race 六组41叶例通过，2.947s，包含共享回填推进
  的冲突、所有权与尺寸回归，无跳过或数据竞争。
- Linux arm64/CGO0 包 vet 通过；本片没有新增 Docker 或真实 etcd 验收。
- host/race/Linux vet 分别9051/9056/9143份实际输入；17类源码、工具、前后字节和
  全部归档成员已独立核对，race 的列表及执行命令均包含 -race。

host 日志 SHA256 `a4cb3929ae39f28ae3874cfafbe803a2b78a2323cdceef3826290824e84ac7cc`；
race `626396d93d680e3781fc8d30b96115c8c03925dfe0bb96de6d0ae9cc2f735fb0`。

host 拒绝输入没有真正签名证明和完整正常构造配置，只能证明拒绝、无调用和无扣费，
