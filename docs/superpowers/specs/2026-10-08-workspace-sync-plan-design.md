# Canonical workspace sync plan

Prerequisite: guarded archive delivery accepted7ff21af. Parent approved etcd migration and tracked trusted-workspace-sync-preparation.md remain authority. This unit supplies an actual canonical plan and a checked native reservation entry point, not provider execution, consumer IO, settlement or production migration.

## Contract

`TaskWorkspaceSyncPlanOptions` contains Workspace WorkspaceIdentity, Exclude []string and DeleteExtraneous bool. `NewTaskWorkspaceSyncPlan(options) (TaskWorkspaceSyncPlan,error)` is pure: no callbacks, filesystem, network, goroutines or retention proportional to sandbox N. Private fields hold copied WorkspaceIdentity, canonical exclusions, explicit deletion policy and versioned framed SHA256 digest. WorkspaceIdentity already binds provider, storage identity hash, bucket and canonical prefix. Only existing providers local/s3/cos/oss/obs/minio accepted, by storage provider constants. Do not add endpoints/credentials or raw storage identity to this value or logs; physical adapter verification remains later work.

Input exclusions: at most256 entries, each at most4096 UTF8 bytes, aggregate at most16384 bytes before canonicalization; unix relative clean paths, depth at most128. Reject empty/root/dot, absolute, traversal, repeated separators, trailing slash, backslash, invalid UTF8 and control bytes instead of silently changing invalid legacy input. Literal '*' is a literal name, not a glob. Preserve existing valid exclusion semantics: exact path or descendant separated by '/'; `.agent` does not match `.agentx`. Sort and deduplicate exclusions, remove those already covered by a parent so semantically equivalent lists have identical digest. Validate resource limits before copying/sorting. Bounds are per plan, not per idle sandbox.

Digest domain `sandbox.task-workspace-sync-plan.v1` binds full immutable WorkspaceIdentity components, deletion policy and canonical exclusion count/entries with existing length-framed hashing. Mode is exactly sync. No arbitrary caller digest override. Different physical storage identity, provider, bucket, prefix, exclusion semantics or deletion policy must change the digest. Nil and empty exclusions equivalent. Returned plan is immutable value data, safely copyable, not an original executable capability. Zero/forged inconsistent private values refuse.

Methods: `FinalSyncPlan() (TaskFinalSyncPlan,error)` returns validated sync/digest metadata; `MatchesAttempt(TaskFinalSyncAttemptRecord) error` requires valid complete record, exact workspace hash, sync mode and plan digest; `Excludes(string) (bool,error)` validates canonical relative candidate (a single trailing slash may represent a directory) before applying exclusion semantics. No public raw target/credential getter; no artifact reader or provider request callback. MatchesAttempt is structural attribution, not current native authorization or evidence of no remote effects.

`Backend.ReserveTaskWorkspaceSync(context.Context,*TaskClaim,*PreparedTaskQuiescence,*controltransport.Destination,TaskWorkspaceSyncPlan) (TaskFinalSyncReservationResult,error)` first validates plan and original Backend/claim/prepared seals, then under claim mutex verifies exact pinned task WorkspaceHash. Mismatch returns ErrIdentityMismatch before destination query, native transaction or original final-sync draft/attempt creation. Invalid plan returns ErrInvalidRecord. It then delegates the unchanged accepted ReserveTaskFinalSync, preserving current native/quiescence/one-shot/unknown-response behavior and existing protobuf caps. No parallel reimplementation or strengthening of existing public metadata-only API.
