# Linux Node Observer Physical Termination Precursor Design

This implements the concrete physical producer required by the approved etcd migration master. Baseline0488e3c6589a86075e063fd86dd05215edd6a19f; local finalization is a separate active Task. This precursor must actually enroll, terminate, join, durably sign and query a real Linux runtime; metadata-only scaffolding is insufficient. It does not implement etcd termination writers, enrolled publication, owner release, manager/main, manifests, rollout, cloud/FUSE/none/Docker or archive reclamation. Those remain mandatory later master work. No production acceptance from this precursor.

The numbered clauses below preserve the architecture contract IDs for cross-reference; an excluded reference is context for later integration, not an additional task. When clauses mention deployment or later Backend publication, this Task defines compatible producer wire only. No live deployment/cluster changes are authorized here.
