# Target workspace archive producer design

Implement the approved final-sync path's durable target admission and actual source producer, following accepted physical source/user access and signed archive protocol. Two coherent source commits: admission/recovery, then synchronous source/terminal producer. Supervisor routing, backend send fences, receiver verification and provider settlement remain later integration; neither of these commits establishes production migration or release.

## Original admission

`Journal.AcceptWorkspaceArchive(ctx, evidence, originalQuiescence, receipt)` returns an opaque original `*AcceptedWorkspaceArchive` only after durable pending persistence and fresh reauthentication. Require original clean fresh journal/activation, known accounting, closed DATA and USERS, exact original `AcceptedUserQuiescence` owned by that journal with a successful terminal, and exact retained users-quiesce.json terminal. Authenticate archive ticket against the original installed issuer, exact context/windows/digest; compare its historical quiescence context/ticket digest with that original terminal. Clone receipt<=12288 and verify its runtime signature, original times and digest. Fresh exact runtime certificate must cover the whole archive session and match independent birth public key. Syntax/revision ordering cannot replace backend current claim/KV fences.

Capture an immutable monotonic session deadline from trusted current UTC before the first pending write, conservatively subtract1second for uncertainty. It is determined by signed SessionNotAfter, not the short admission context deadline. Duplicate exact live pending admission may return only the same original handle without IO or extending that deadline; changed attribution, another handle or cold history cannot create a producer. Pending is retained on all uncertainty; post-write authentication failure poisons the original journal and returns no handle.

## Protected records and recovery

Fixed root file `workspace-archive.json`; temp `.workspace-archive.<UUID>.tmp`. `TaskWorkspaceArchiveRecord` is unsigned diagnostic history: Version, State pending/archive_complete, Context, TicketDigest, NotBefore/NotAfter/SessionNotAfter, ArchiveBytes/EntryCount/SHA256. Pending requires zero summary. Terminal uses the protocol's bounded summary invariants. Expose three pure `Validate()` wrappers on the already accepted protocol context/ticket/receipt claims so journal code can reuse semantic validation without copying validators or authenticating cold data.

Strict journal schemas reuse existing nested close/quiescence schemas; pending omits summary, terminal requires it. Record limit16384. Read/persist uses existing protected file, no-symlink/inode/type/link/owner checks and temp write/file-sync/rename/directory-sync contract. Admission reserves pending+maximum terminal peak and2 content-file slots under current byte/file/85percent limits. Count retained archive bytes and every temp exactly, no point-operation directory scan or automatic temp cleanup.

Cold scanner accepts same-attribution pending/terminal temps but rejects conflicting attribution or different terminal summaries. Any archive file requires actual retained activation, closed gate and actual retained users-quiesce.json in users_quiesced state, with exact historical context/ticket linkage. A temp alone cannot substitute for retained terminal or pending state. Cold Lookup returns retained copied structural record only. `fresh=false` and absent original handles prohibit admission, streaming or signing even if all files/signatures are readable. Preserve original accepted command/gate/quiescence bytes and accounting behavior.

## Actual synchronous producer

`Journal.StreamWorkspaceArchive(ctx, accepted, source, destination, runtimeKey) ([]byte,error)` owns actual `source.WriteArchive` and derives completion from its returned summary; there is no public arbitrary-summary completion setter. Require original accepted handle, exact pending record and original quiescence terminal, structurally consistent independent birth runtime key, fresh original runtime/issuer certificates, unexpired immutable session and valid context. Consume stream once under j.mu before any destination byte. Context lifetime is min caller stream context and original monotonic deadline; never reuse or extend the admission context/ticket start window.

Release j.mu during physical source/TAR/destination writes. Actual source must be original launcher source supplied by the trusted producer, with fixed /workspace confinement and user policy selected from verified birth by future Supervisor. Copied/foreign source rejection, failed or panicking writer, context error and zero summary yield no completion. A streaming failure poisons journal, retains pending and never revives/resends the source. Normalize writer panic to conservative error after launcher defer closes source; do not swallow success. Journal cannot force arbitrary blocked IO to return.

After actual source success, under j.mu verify exact original live pending/terminal records, session/context, key and original certificates again; persist bounded terminal with real summary; reauthenticate before signing receipt and before returning it. Failures retain poison/pending-or-readable-terminal uncertainty; no signature escapes. Original successful accepted handle may re-sign identical historical terminal under fresh runtime certificate with fresh census/context, never stream again. Cold/poisoned/copied handles cannot sign.

`Close` sets closed/cancels the registered archive stream under j.mu, releases that mutex, waits for its physical source/writer/persistence owner to finish, then closes journal descriptors. Preserve non-archive Close behavior. No lock held during wait; source remains owned until physical return. Close from inside an in-flight writer would wait for that same writer and is outside the trusted IO contract. Future Supervisor must own an independent process-isolation deadline for blocked IO; Journal cancellation alone is not termination or release evidence.
