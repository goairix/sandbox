# Chart 0.3.0 与 Sentinel 升级整洁性验证

## 范围

本轮只把 Helm Chart `version` 升级为 `0.3.0`，`appVersion` 和所有镜像 tag 未改。
同时完成 Sentinel 一次性 Job 条件渲染、API-only 升级快照比较器和 FUSE refill
lease 45 秒接管的 opt-in 集成测试入口。

普通沙盒销毁耗时和 FUSE 创建长尾不属于本轮。

## 模板状态矩阵

`internal/helmtest/sentinel_job_lifecycle_test.go` 通过临时 Chart 注入 lookup fixture，
不增加生产 values 测试开关。实际覆盖：

- 离线全新安装：identity/initialize Job 及 RBAC 均存在；
- `Pending` 且身份 Secret 已存在：仅 initialize Job/RBAC 存在；
- `Initialized` 且身份 Secret 已存在：两个 Job/RBAC 均不存在，Redis StatefulSet、
  state ConfigMap、Service 和 NetworkPolicy 仍存在；
- retained state 缺身份 Secret：模板失败；
- phase 为空、`Ready` 或大小写错误：模板失败。

测试先在旧模板上观察到 initialized/pending 用例失败，再增加 helper 状态字段和模板
条件；最终完整 helmtests 通过。

## 安全边界

升级比较器只读取 Deployment、StatefulSet、Pod 和 Job 元数据，不执行 Helm upgrade，
不读取 Secret。snapshot 使用 `0600` 临时文件并原子替换目标文件。

FUSE lease 测试必须显式设置 `SANDBOX_REFILL_LEASE_TEST=1`。它在创建 sandbox 前要求
唯一、完整、全 prepared 的 FUSE pool；不满足则停止。测试不删除 refill lock，异常
退出依赖生产协议的 45 秒 TTL 恢复；不删除 PVC、身份 Secret、Sentinel state 或非测试
资源。
